# CS_gov — محاكي الرخصة المهنية 1448 (حاسب آلي)

محاكي تدريبي تفاعلي: **المعيار ← المؤشر ← السؤال** مع شرح لكل خيار، وطريقة حل مفصّلة تُكشف خطوة خطوة، وتتبّع لكيفية الوصول إلى كل خيار خاطئ.

> **تنبيه:** مشروع تدريبي شخصي **غير رسمي** وغير تابع لهيئة تقويم التعليم والتدريب. الأسئلة مؤلَّفة بمساعدة الذكاء الاصطناعي **ولم تُراجَع بشريًا بعد**. المؤشرات منقولة من غلاف كتاب تجاري لا من الوثيقة الرسمية. لا تعتمد عليه وحده.

## بنية الصفحة
صفحة واحدة `index.html`: صفحة رئيسية ببطاقات المعايير الـ16 (المبنية مفعّلة والباقي «قريبًا») + اختبار شامل بنسبة أوزان الكتاب. كل معيار يُضاف بملف بيانات `data/standard-NN.js` ومولِّدات `js/generators-mNN.js` وتسجيل في `data/standards.js`.

## المحتوى الحالي
### المعيار 1: الرياضيات
- 23 سؤالًا ثابتًا لها خطوات حل وتحقق وتتبّع أخطاء (`data/standard-01.js`، مولَّد من `tools/build_bank.py` مع تحقق حسابي).
- 16 قالبًا مولِّدًا (`js/generators.js`): نسخة جديدة كل مرة، وكل مشتّت ناتج عن نموذج خطأ مسمّى.
- تدريب، مراجعة متباعدة، اختبار مصغّر، واختبار ممتد (20/30/45) بمؤشر وتيرة وعلامة «للعودة» ومتنقّل وتقرير الأبطأ.
- الإحصاءات للمولَّدات على مستوى القالب لا النسخة.

### المعيار 2: التصميم المنطقي
- 37 سؤالًا ثابتًا (`tools/build_bank_m02.py`) و9 قوالب مولِّدة (جامع كامل، Decoder، Encoder، MUX، جامع متتابع، تتابع القلّابات، العدّاد، عدد القلّابات، نقل التوازي/التوالي). أربعة أسئلة موسومة «تعزيزي» لأنها تتجاوز نص الكتاب.

## التشغيل
افتح `index.html` مباشرة، أو انشره عبر GitHub Pages. لا اعتماديات.

## الاختبارات
```
python3 tools/build_bank.py data/standard-01.js   # يتحقق من كل جواب ومشتّت وتتبّع
python3 tools/build_bank_m02.py data/standard-02.js
node tests/test_generators.js                     # إعادة حساب مستقلة لآلاف النسخ
```

## حدود معروفة
- عدد الأسئلة وزمن الاختبار الرسميان غير موثّقين؛ الوتيرة تقدير (7200 ÷ 88 ثانية) ويُضبط عبر `window.CS_CONFIG`.
- لا نسخ من نص الكتاب ولا من تجميعات الأسئلة المتداولة.
- الترخيص: **لم يُحدَّد بعد** (قرار صاحب المستودع).
